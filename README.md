# workout_aftermath
Workout Tracker for Self, Friends and Family

💪 Bold Body Agenda: a simple tracker for food, water, workouts, sleep and weight.

👉 [YOUR-LINK-HERE](https://ramaditya524.github.io/workout_aftermath/)

Set it up as an app (takes 20 seconds):

iPhone: open the link in Safari → tap Share (square with arrow) → Add to Home Screen → Add.
Android: open the link in Chrome → tap ⋮ (top right) → Add to Home screen (or Install app).

Always open it from the new icon, not the browser. On iPhone that stops Safari from clearing your data.

Good to know:
- No account, no server. Your data stays on your phone only. I can't see it.
- Back up once a week: Settings → Copy backup → paste into Notes/Keep. Restore from the same screen if you change phones.
- Ask AI doesn't run any AI itself. It builds a question with your data and opens Claude, ChatGPT or Gemini for you to paste into.
